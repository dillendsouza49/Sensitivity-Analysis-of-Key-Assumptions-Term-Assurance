# Sensitivity Analysis of Key Assumptions – Term Assurance

Sensitivity analysis of a Term Assurance product using Microsoft Excel to evaluate the impact of changes in premium, sum assured, and interest rate assumptions on product profitability.

The objective is to identify key profitability drivers and understand how changes in individual assumptions influence the financial performance of the product.

## Technologies Used

- **Microsoft Excel:** Financial modelling, calculations, sensitivity analysis and data visualisation.

### Key Concepts

- Actuarial Valuation
- Premium and Claim Cost Analysis
- Present Value of Future Liabilities
- Profitability Analysis
- Break-even Analysis
- Sensitivity Analysis

## Base Scenario – Model Inputs and Assumptions

The following assumptions were used to establish the base scenario for the Term Assurance profitability model.

| Parameter | Base Assumption |
|---|---:|
| Mortality Table | AM92 (Actuarial Booklet) |
| Age at Entry | 30 years |
| Policy Term | 25 years |
| Annual Premium | ₹3,500 |
| Sum Assured | ₹2,500,000 |
| Initial Expenses | ₹1,500 |
| Renewal Expenses | ₹400 |
| Initial Commission | 35% of Premium |
| Renewal Commission | 5% of Premium |
| Claim Expenses | ₹750 |
| Expense Inflation | 1.25% |
| Interest / Risk Discount Rate | 8% |

These base assumptions form the reference point for the sensitivity analysis. Individual assumptions were varied while keeping the remaining assumptions constant to evaluate their impact on product profitability.

## Features of the Project

- Analysis of three key assumptions affecting product profitability:
  - Premium
  - Sum Assured
  - Interest Rate
- Evaluation of profitability under different assumption scenarios.
- Identification of break-even points for each assumption.
- Visualisation of changes in profitability using charts.
- Assessment of the relationship between individual assumptions and product profitability.

## Project Process

1. **Base Model:** Establish a Term Assurance valuation model using the base assumptions.
2. **Sensitivity Analysis – Premium:** Vary premium levels while keeping other assumptions constant to evaluate their impact on profitability.
3. **Sensitivity Analysis – Sum Assured:** Vary the sum assured to assess changes in expected claim liabilities and product profitability.
4. **Sensitivity Analysis – Interest Rate:** Change the interest rate assumptions to examine their impact on the present value of future liabilities.
5. **Profitability Assessment:** Calculate the resulting profit or loss under each scenario.
6. **Visualisation and Interpretation:** Use charts to compare results, identify break-even points and interpret the impact of each assumption.
